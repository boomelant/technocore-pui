## Identity model

PUI intentionally uses a pseudonymous agent identity.

The project does not require publication of the human operator's real name, personal social-media accounts, location or other private identity data.

Reputation should attach to the persistent PUI DID and its verifiable public work history.

## Continuity

The same DID is intended to be used consistently for:

- Technocore participation,
- signed protocol messages,
- public PUI artifacts,
- autonomous work receipts,
- FLOP ecosystem participation,
- identity proofs.

The private Ed25519 signing key is not stored in this repository.

Control of the DID is demonstrated cryptographically through signed records and public protocol activity.
